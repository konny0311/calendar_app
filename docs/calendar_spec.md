# v1 仕様（MVP版）

## 目的
- ユーザーがカレンダーUIで日時や時間帯を直感的に選び、**フォーマット済みテキストをワンクリックでコピー**できること。
- このアプリが日常で役立つかを確認する。

## 対象
- Webアプリ（デスクトップ/モバイルブラウザ）  
- PC/スマホ両方で利用可能  
- クリップボードコピーは `navigator.clipboard.writeText` を利用

## 機能スコープ
- ✅ カレンダー表示（月/週/日）  
- ✅ 日時選択（クリックで日付、ドラッグで時間範囲）  
- ✅ 複数日選択（同一の時間帯を複数日へ適用）  
- ✅ 時間帯は15分刻み  
- ✅ 複数の時間帯を選択（数の上限なし）  
- ✅ 出力プレビュー（例: `10/12(日) 14:00–15:30`）  
- ✅ 「コピー」ボタン（成功時に短いトースト表示）  
- ✅ 最小限の書式（日本語、`YYYY/MM/DD(曜) HH:mm–HH:mm`）  
- ✅ タイムゾーンは Asia/Tokyo 固定  

### 含まない（将来検討）
- 複数候補管理（別時間帯やメモなどの管理）  
- 書式テンプレ編集  
- 深い設定機能（丸め、祝日表示、和暦など）  
- Deep Link/共有URL  
- モバイルネイティブ機能

## UI概要
- **ヘッダー**：月移動（前月・今日・次月）  
- **メイン**：カレンダー（日/週ビュー推奨）  
- **右ペイン or 下部**：  
  - 選択した日時（複数日可）のテキストプレビュー（1行/1日）  
  - 「コピー」ボタン  
  - 「時間帯をクリア」ボタン（選択済みの時間帯を全削除）
  
### スクロール・表示挙動（週/日ビュー）
- カレンダー領域は内部スクロール。
- 縦スクロール時、各日の見出し（例: `10/6(Mon)` など）のヘッダー行を上部に固定表示（sticky）。
- スマホ幅でも週ビューは7列で画面幅に収まる（横スクロールなし）。各日の列幅は自動で縮小し、時間ラベル用に左端44pxを確保。

## データ構造（簡易）
```ts
type Slot = {
  start: string; // ISO8601, e.g. "2025-10-12T14:00:00+09:00"
  end: string;   // ISO8601
};

type State = {
  selectedDates: string[]; // YYYY-MM-DD in Asia/Tokyo
  timeRange?: { startMin: number; endMin: number }; // 分（0..1440）
};
```

## 出力フォーマット
- 例）`2025/10/12(日) 14:00–15:30`  
- 終日選択 → `2025/10/12(日) 終日`  
- 複数日 → 各日1行で並べ、コピー時は改行区切り

## 成功/失敗挙動
- 成功：画面下部に「コピーしました」トースト（3秒）  
- 失敗：テキストエリアを選択状態にし、「Ctrl+C / Cmd+Cでコピーしてください」案内

## 技術スタック
- React + TypeScript + Vite  
- 日付処理：date-fns  
- スタイル：Tailwind（シンプルでOK）

## 操作仕様（複数日・複数時間帯）
- 月ビュー：日付をクリックで選択/解除（トグル）。
- 週/日ビュー：ドラッグで時間帯を追加。ドラッグした日の選択が自動的にオンになる。
- 週/日ビュー：クリックしたままドラッグすると、連続する時間帯を一括選択できる。
- 複数回ドラッグして複数の時間帯を追加可能（重なりは自動マージ）。
- 追加した時間帯は全選択日に適用（共通）。
- 終日は 00:00–24:00 の選択で表現。
 - 週/日ビュー：選択済みの時間帯上をクリックすると、その15分スロットを削除（トグル）。
   - 範囲の途中をクリックした場合は、そのスロット分だけ除去し、残りは左右に分割して保持。
